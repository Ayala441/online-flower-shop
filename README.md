# Шағын онлайн гүл дүкені (Online Flower Shop)

PHP және MySQL қолданып әзірленетін оқу жобасы.

## Жобаның мақсаты
Пайдаланушыларға онлайн режимде гүлдер мен букеттерді таңдап, себет арқылы тапсырыс беруге мүмкіндік беретін веб-қосымша құру.

## Негізгі беттер тізімі
1. `index.php` - Басты бет
2. `catalog.php` - Каталог және іздеу/сүзу беті
3. `product.php` - Өнімнің толық сипаттамасы
4. `cart.php` - Себет және тапсырыс рәсімдеу
5. `login.php` / `register.php` - Кіру және тіркелу жүйесі[cite: 1]

## Дерекқор құрылымы (MySQL - 4 кесте)
- `users` (Пайдаланушылар)
- `categories` (Гүл санаттары)
- `products` (Тауарлар)
- `orders` (Тапсырыстар)
